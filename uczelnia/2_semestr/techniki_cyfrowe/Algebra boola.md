# Transformacje
- Tablica prawda → wyrażenia algebraiczne 
- Tablica prawdy → schemat logiczny
- Wyrażenia algebraiczne → schemat logiczny
- Wyrażenia algebraiczne → tablica prawdy
- Wyrażenia algebraiczne → inna postać wyrażenia algebraicznego
- ...

Przekształcanie służy redukcji liczby bramek i/lub liczby wejść

W technice cyfrowej nie chodzi o robienie bramek tylko o automatyzacje tego.
